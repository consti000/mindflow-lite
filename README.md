# MindFlow Lite

생각을 빠르게 적고, 구조화하고, 다시 꺼내는 개인용 마인드맵 노트입니다. 서버와 로그인 없이 브라우저에 저장되는 Local-first PWA입니다.

**배포:** https://consti000.github.io/mindflow-lite/

## 기능

- 마인드맵 캔버스, 아웃라인 보기
- 자식/형제 노드, 단축키, 실행 취소
- IndexedDB 자동 저장
- JSON 가져오기/내보내기, PNG 내보내기
- 노트북 키보드와 태블릿(S Pen/터치) 조작

## 로컬 실행

```bash
npm install
npm run dev
```

`main`에 푸시하면 GitHub Pages에 자동 배포됩니다.
